# ADR 0029: 디자인 시스템 아키텍처

- 상태: 채택
- 날짜: 2026-10-01

## 맥락

전자칠판, 웹, 앱, 인터랙티브 콘텐츠, 종이 학습지가 같은 시각 언어와 같은 문항 데이터를 써야 한다. 디자이너 없이 일관성을 유지해야 하고, 표면마다 입력 방식(펜·터치·마우스)과 거리(교실 뒷자리~손 안)가 다르다.

## 결정

1. **토큰이 진실의 원천이다.** DTCG JSON → CSS 변수. React가 아닌 환경(정적 HTML, 인쇄 CSS)도 같은 값을 쓴다.
2. **표면 프로파일은 토큰 오버라이드 레이어다.** `data-surface` 하나로 간격 단위, 글자 배율, 터치 타겟이 바뀌고 컴포넌트는 표면을 모른다.
3. **1차 구현은 React 19 + TypeScript + 순수 CSS(`@layer`).** 접근성 동작은 Radix 헤드리스 프리미티브를 쓴다.
4. **아이콘은 Phosphor Icons(MIT) Regular(`ph ph-*`) 단일 표준.** 처음에는 Flaticon UIcons를 썼으나 출처 표기 의무가 있는 라이선스라 오픈소스(MIT) 저장소와 맞지 않아 교체했다. 글꼴은 소비자가 `@phosphor-icons/web`으로 직접 불러온다.
5. **종이 학습지는 같은 문항 스키마를 쓰는 인쇄 전용 정적 렌더러다.** 화면용 컴포넌트를 재사용하지 않는다(인쇄에는 입력 위젯이 없다).
6. **판서 엔진은 어댑터다.** 코어는 `InkLayer` 인터페이스만 정의하고 tldraw/Konva에 의존하지 않는다.
7. **문항은 QTI 3.0 부분집합(choice, cloze, matching, ordering, hotspot, short-answer)을 zod로 정의한다.**
8. **개발 중에는 소스를, 배포 시에는 `dist`를 가리킨다.** 각 패키지의 `main`/`exports`는 `src`, `publishConfig`가 `dist`로 덮어쓴다.

## 기각한 대안

- **Tailwind + shadcn/ui**: 소비자가 CSS 변수만으로 쓸 수 없고, 토큰·표면 프로파일 계약과 충돌한다. 클래스 유틸리티가 4/8pt 스케일 밖 값을 허용한다.
- **웹 컴포넌트 우선**: Vue/Svelte까지 한 번에 커버하지만 접근성 프리미티브와 테스트 생태계가 React보다 얇다. 토큰 CSS가 이식 가능하므로 필요할 때 래퍼를 추가한다.
- **화면 컴포넌트를 인쇄에 재사용**: `button`/`input`이 종이에 나오고 `break-inside` 제어가 어렵다.
- **Storybook**: 초기에는 Vite 쇼케이스 + 실브라우저 캡처 검사가 더 가볍고 실제 렌더 검증과 직접 연결된다.

## 결과

- 표면이 늘어나도 컴포넌트 수정 없이 토큰 파일만 추가하면 된다.
- 터치 타겟·대비·간격 하한은 테스트와 `spacing-lint`가 강제한다.
- 한계: 실제 전자칠판 하드웨어(멀티터치·펜) 검증은 하지 않았다. 교실 거리 가독성 수치(본문 28pt+, 타겟 64px+)는 잠정값이다.
